Language trip prices

Five customer requests, priced from the catalog. Every amount below is calculated by src/pricing.js from src/catalog.js when the page loads. All prices are in euros.

Quotes

Pricing rules used

  • Course: weekly rate × weeks. From 4 weeks on, the lower long-stay rate applies to all weeks.
  • Enrolment fee: once per booking, per school.
  • Accommodation: weekly rate × weeks. Only the types listed for that school exist.
  • Seasonal supplement: belongs to the accommodation. Charged per week for each stay week whose Monday falls in the listed ISO weeks (inclusive).
  • Stays start on the Monday given and last whole weeks.

How I worked

Main prompts to Claude Code

  1. Analysis before code. “Extract the catalog and five requests, calculate each one line by line, show the ISO week of every Monday, apply the long-stay rate to all weeks from 4 weeks, list options instead of a partial total. Stop so I can check your answers.” I checked the figures by hand before allowing any code.
  2. Build it. Static HTML, CSS and JavaScript; catalog and requests as data; pricing in its own module; ISO weeks in UTC; no substitution for unavailable accommodation. Tests for the five requests, the 3 versus 4 week boundary, ISO weeks 25/26/35/36, no accommodation in season, accommodation without a supplement, and the year boundary.
  3. Run the tests under Node, then deploy only the site files using Cloudflare's skills, then publish the source and add this section.

One thing it got wrong, and how I caught it

Claude Code reported that Node.js was not installed, because node was not on the PATH, and worked around it by running the tests in a browser. When I asked it to install Node, the installer failed. The installer log said a newer Node.js (v26) was already installed in C:\Program Files\nodejs but missing from the PATH. Claude Code then ran npm test with that Node. All 22 tests passed, including runs in three time zones from UTC−11 to UTC+14.

How I checked its work

  • Confirmed the hand calculation (€2,220 / €1,485 / €1,800 / €1,840 / not available) before any code was written.
  • Broke the 4-week rule on purpose. The relevant tests failed (€1,040 instead of €940), then passed again after reverting.
  • Compared the ISO-week function with Python's isocalendar() for every day from 2020 to 2032 (4,749 days, identical).
  • Checked the live site: correct totals, phone width without horizontal scroll, and no stray files (the tests and the task PDF return 404).

How it reached Cloudflare

Wrangler (via Cloudflare's skills in Claude Code), signed in with wrangler login. Wrangler 4.151 now sends new Pages projects to Workers, so the site is served as Workers static assets. npm run deploy runs the tests, copies only index.html, styles.css and src/ into dist/, and runs wrangler deploy.
